# 📊 Gerador Interativo de Gráficos

Aplicação web interativa e responsiva para criação e visualização rápida de gráficos sem a necessidade de APIs pagas ou serviços externos.

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** HTML5, CSS3 Responsivo e JavaScript Vanilla.
- **Engine de Renderização:** [Chart.js](https://www.chartjs.org/) via CDN.
- **Ambiente de Desenvolvimento:** GitHub Codespaces.

---

## 📈 Tipos de Gráficos Suportados

1. **Pizza (Pie Chart)**
2. **Colunas (Vertical Bar Chart)**
3. **Barras (Horizontal Bar Chart)**
4. **Linhas (Line Chart)**
5. **Área (Filled Line Chart)**
6. **Histograma (Frequency Bar Chart)**
7. **Dispersão (Scatter Plot)**
